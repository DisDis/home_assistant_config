# Правила работы с проектом

## Проверки Docker Compose

Не запускать и не расширять перебор сочетаний Compose-профилей и переходов между ними, если пользователь отдельно не попросил такую проверку. Работа штатного механизма профилей Docker Compose считается установленной.

При изменениях проверять адресно затронутую конфигурацию, сервис и команды управления. Для переноса контейнера достаточно проверить его описание, пути данных и параметры запуска; для изменений документации — приведённые команды и ссылки. Не повторять проверки, которые уже прошли, без новых изменений, ошибок или конкретной нерешённой проблемы.

# Yandex Smart Home через HACS

[Yandex Smart Home](https://github.com/dext0r/yandex_smart_home) передаёт выбранные устройства Home Assistant в «Дом с Алисой». Это пользовательская интеграция HA; отдельного Docker-контейнера и профиля Compose у неё нет. Установка, обновление и отключение выполняются отдельно от `plugins.sh`. По умолчанию компонент не устанавливается.

## Установка

1. Проверьте совместимость установленной версии HA с выбранным релизом компонента. Документация ветки 1.1.x указывает HA 2025.12 или новее; перед обновлением сверяйте требования [актуальной документации](https://docs.yaha-cloud.ru/v1.1.x/).
2. Откройте HACS. Если его нет, следуйте [официальной инструкции для своей версии HA](https://www.hacs.xyz/docs/use/download/download/), выбрав Home Assistant Container. В версиях HA с встроенным Marketplace используйте доступный интерфейс HACS/Marketplace; повторно устанавливать существующий HACS не нужно. Для старых версий инструкция HACS предусматривает загрузку внутри контейнера, перезапуск HA и добавление HACS через интерфейс интеграций.
3. В поиске HACS найдите **Yandex Smart Home**, проверьте репозиторий `dext0r/yandex_smart_home`, скачайте выбранный совместимый релиз.
4. Перезапустите Home Assistant. На сервере, где основной стек находится в `/home/hauser/home_assistant_config/homeassistant`:

   ```bash
   cd /home/hauser/home_assistant_config/homeassistant
   docker compose restart homeassistant
   ```

5. Откройте **Настройки → Устройства и службы → Добавить интеграцию → Yandex Smart Home** и завершите мастер. Это порядок установки, [рекомендованный автором](https://docs.yaha-cloud.ru/v1.1.x/install/component/).

## Подключение к Яндексу

Выберите подходящий [тип подключения](https://docs.yaha-cloud.ru/v1.1.x/config/connection-type/): облачное Yaha Cloud проще в настройке; прямое требует постоянного доступа к HA из интернета и настройки HTTPS. Настраивайте выбранный вариант по документации компонента. Сам перенос Compose не публикует HA в интернете и не настраивает привязку аккаунта.

Задайте список устройств для передачи Яндексу, свяжите интеграцию в приложении «Дом с Алисой» по шагам мастера и проверьте команду для одного устройства. После этого добавьте остальные нужные устройства. Учётные данные и рабочие настройки сохраняются локально в каталоге HA; их не нужно переносить в Git или `plugins/.env`.

## Обновление, отключение и бэкап

Обновляйте компонент через HACS после проверки совместимости и резервного копирования `homeassistant/config/`, затем перезапускайте HA. HACS сохраняет файлы компонента в `/config/custom_components/yandex_smart_home`, что соответствует `homeassistant/config/custom_components/yandex_smart_home` на хосте.

Для временного отключения используйте меню записи интеграции в **Настройки → Устройства и службы**. Для полного удаления сначала удалите запись интеграции и отвяжите соответствующее подключение в «Доме с Алисой», затем удалите компонент через HACS и перезапустите HA. Изменение `COMPOSE_PROFILES` на эту интеграцию не влияет. В резервную копию включайте весь `config/`, включая `.storage` и `custom_components`; каталог уже исключён из Git.

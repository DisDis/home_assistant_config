# Zigbee2MQTT

Сервис и профиль `zigbee2mqtt` определены в [общем Compose](../docker-compose.yml); по умолчанию профиль выключен. Образ и путь координатора задаются в `plugins/.env`. Данные находятся в `plugins/zigbee2mqtt/data/` на хосте и `/app/data` в контейнере.

Инструкция включения, первоначальной настройки и обслуживания сети: [plugins/README.md](../README.md#zigbee2mqtt-и-file-editor). Для бэкапа остановите контейнер и сохраните весь `data/`, включая `configuration.yaml`, базу устройств и резервную копию координатора. Повторное создание контейнера не удаляет данные; не проходите создание новой сети поверх существующей.
